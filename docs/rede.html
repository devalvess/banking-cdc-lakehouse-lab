A rede do Banking Lab, peça por peça

Como o Databricks alcança o "datacenter" sem passar pela internet, quem pode falar com quem e por quê o serverless fica de fora. Use Próximo ou as setas ← → do teclado.

peering dados (Databricks → on-prem) SSH e túnel (você → VM) controle (HTTPS e saída pelo NAT) sem rota

Ícones: onde achar cada peça no portal do Azure

  • Subscription (assinatura) · a sua assinatura Azure
  • Resource group · rg-onprem-simulado e o RG gerenciado databricks-rg-…
  • Virtual network · vnet-onprem e workers-vnet
  • Subnet · dentro da VNet, em Settings → Subnets
  • Peering · na VNet, em Settings → Peerings
  • Network security group · nsg-servidores e workers-sg
  • Virtual machine · vm-onprem-db2
  • Public IP address · pip-vm-onprem-admin
  • NAT gateway · no RG gerenciado do Databricks
  • Storage account · dbstorage… (ADLS Gen2)
  • Azure Databricks · o workspace, no seu resource group
  • Docker · roda dentro da VM, não aparece no portal

Ícones desenhados no estilo dos ícones oficiais do Azure. O conjunto oficial (Azure Architecture Icons) pode ser baixado no Microsoft Learn para usar no draw.io.
